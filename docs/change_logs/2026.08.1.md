Fleet-standards alignment: zero-vuln dependencies, mypy driven to zero, full luxarch/luxlint/luxaudit conformance, CalVer versioning, and canonical build provenance. First CalVer release (SemVer `1.1.x` retired).

## Security

- **python-jose → PyJWT** (LUXUPT-66). The `cryptography` (CVE-2026-69247) and `ecdsa` advisories were transitive via `python-jose[cryptography]`; PyJWT signs HS256 with the standard-library `hmac`, pulling neither. luxaudit went 1-vulnerable + 1-deferred → 0. JWT behavior unchanged; added round-trip + rejection-path tests.

## Features

- **Static asset cache-busting** — first-party CSS/JS carry `?v={{ static_version }}`, where `static_version` is the short git SHA (`BUILD_COMMIT`), the same value stamped as `org.opencontainers.image.revision`. Browsers refetch immediately after a deploy; no configuration.
- **Component library** (`/system/components`, dev mode) — the showcase renders every public UI macro from sample objects, so the branded macro library stays complete and discoverable.

## Refactors

- **mypy tail → 0** (LUXUPT-64). Fixed the tail env first (install the real deps from the lock, killing ~105 phantom `untyped-decorator` errors: 227 → 122 honest), then drove 122 → 0 with clean fixes only — `dict[str, Any]` annotations, a narrowed `execute_rowcount` DML helper, a `TYPE_CHECKING` `Base.id`, no `cast`/`type: ignore`. Ratchet baseline is 0.
- **DB session unification** (LUXUPT-30) — two transaction owners (request `get_db` / non-request owned sessions); irreversible side effects moved behind an `after_commit` helper (delete the row, then the file); redundant commits removed.
- **Router domain split** — `timelapses_router` → `timelapses` / `timelapse_jobs` / `timelapse_scheduler`.
- **Layout** — `src/app` → `app/` (LUXUPT-65); `static` → `app/static`; web templates → `app/templates/web` (fleet-canonical).
- **ruff burndown** (LUXUPT-63) — TRY400/G201/LOG015/S105-S106/PLC0415.
