# 2025.10.1 — 2025-10-15

Packaging/build modernization. (Released as `1.1.0` under SemVer; re-versioned to CalVer by date.)

## Features

- Poetry dependency management (`pyproject.toml`) replacing `requirements.txt` / `build.sh` / `gather_reqs.sh`.
- Full-featured Makefile — multi-arch builds, local + Docker Hub registries, BuildKit inline cache, poetry/lint/test targets.
- Multi-stage Dockerfile — smaller runtime image, non-root `appuser`, healthcheck, proper layer caching.
- Docker Compose overlays — base `compose.yaml` + one overlay per deployment site, DRY.

## Refactors

- Python 3.11 → 3.13 across all configs.
- Dependency bumps: httpx 0.26→0.28.1, urllib3 1.26→2.5, fastapi 0.104.1→0.119, uvicorn 0.24→0.37, python-multipart 0.0.6→0.0.20, aiofiles 23.2→25.1, pillow 10.1→11.3, psutil 5.9.6→7.1.

## Removed

- `build.sh`, `requirements.txt`, `gather_reqs.sh`, and the individual per-site compose files (replaced by base + overlays).

## Notes

- Version scheme this release moved from date-based (`2025.6.4`) to SemVer (`1.1.0`); the fleet later standardized on CalVer, so this file is re-versioned to `2025.10.1` by its release date.
- Build: `make docker-push-local`. Deploy: `compose -f compose.yaml -f compose.<site>-overlay.yaml up -d`. Python 3.13 required.
