# 2025.10.1 — 2025-10-15

Packaging and deployment overhaul — smaller, faster, multi-architecture images.

## IMPROVED

- **Faster, smaller container** — LuxUPT now ships as a leaner image that runs on both Intel/AMD and ARM hardware (Raspberry Pi, Apple Silicon).
- **Runs as a non-root user** — the container no longer runs as root; a security improvement with no change to how you use it.
- **Platform reliability** — modernized dependencies and build tooling across the board, and moved to Python 3.13.
