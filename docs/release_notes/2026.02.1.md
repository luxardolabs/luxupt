# 2026.02.1 — 2026-02-20

Timelapse reliability — job creation, image cleanup, and clearer error messages.

## FIXED

- **Timelapse jobs wouldn't start** — creating a timelapse job had been failing on every attempt; it works again. (If yours had been stuck for a couple of weeks, this is why.)
- **Old source images now get cleaned up** — after a timelapse rendered, its source snapshots weren't being deleted, so storage kept growing. They're now removed as intended.
- **Camera capture toggle now takes effect** — turning a camera's capture off in the interface now actually stops it capturing.
- **Logs stopped going quiet** — logging could fall silent shortly after startup; it now keeps working the whole time.

## IMPROVED

- **Clearer camera and encoding errors** — when a camera uses H.265/Enhanced encoding, or a render runs out of memory, the logs now say so in plain language and point you to the fix, instead of a generic failure.
