# Release Notes

Per-version, user-facing release notes live in [`app/release_notes/`](app/release_notes/) — what changed for the people who actually use LuxUPT.

- Current: [`app/release_notes/2026.09.0.md`](app/release_notes/2026.09.0.md)
- Format: [`app/release_notes/writing-guide.md`](app/release_notes/writing-guide.md)

The internal, technical half is [`CHANGELOG.md`](CHANGELOG.md). The process that produces both is `luxarch --doc FLEET-RELEASE-PROCESS`.
