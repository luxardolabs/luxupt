# 2026.10.1 — 2026-10-09

The guard bump to luxarch 0.275.4 / luxlint 0.62.2 / luxaudit 0.13.1, onboarded in full: 23 new reds burned down to 1 (escalated). It brought the fleet logging module, the emitted test block, smoke-after-deploy and the Docker CSS stage. Two live bugs came out of it, and an adversarial pass found and fixed six more defects.

19 commits since `v2026.10.0`. Format per `luxarch --emit changelog-guide`.

**Pre-deploy (every environment, before restarting on this image):**

1. **Rename the logging env vars:** `LOGGING_LEVEL` → `LOG_LEVEL`, `LOGGING_FORMAT` → `LOG_FORMAT`, `LOGGING_MODULE_LEVELS` → `LOG_MODULE_LEVELS`. The old names are ignored, so the app falls back to INFO / json.
1. **Set `ALLOWED_HOSTS`** (comma list) to every hostname users reach the site by. localhost and 127.0.0.1 are always added. Unset, the app answers only localhost: every request through nginx gets **400** while the container healthcheck stays green, and startup logs a WARNING. The `.env.bb` prod host is still unnamed (LUXUPT-18).
1. **Ports moved to 11000 (primary site) / 11001 (secondary site)** on dev and prod, from 8001/8002 (dev) and 8888 (prod). Already applied on the dev and prod nodes.

**Post-deploy:** none. No new Alembic revisions.

## Fixes

- **`/timelapses/jobs` and `/timelapses/partials/jobs` 500'd whenever a job was running or pending.** `job_list.html` included `job_progress.html`, which reads `action`, a key only the single-job poll route passes (StrictUndefined). The route smoke never saw it because the test database has no running jobs. Regression test: `test_job_cards_render`.
- **Tailwind content globs still pointed at the pre-layout `app/web/templates` / `app/web/static` paths.** Any rebuild of the stylesheet would have dropped nearly every class; the committed CSS only worked because it predated the move.
- **Forged Host headers were answered.** nginx forwards `$host`, so the app served any name pointed at it. Now `TrustedHostMiddleware` (outermost, refusals logged) from `ALLOWED_HOSTS`. Found by `make smoke`.
- **A Protect URL serving a web page** (a UniFi OS console without Protect) surfaced as `Expecting value: line 1 column 1` on `/health`. Discovery and the RTSPS lookup now raise `ProtectApiUnavailableError`, naming the host and content type.
- **Adversarial pass on the onboarding (9 confirmed):**
  - `ALLOWED_HOSTS` set without localhost broke the healthcheck: localhost is now always kept.
  - Unset `ALLOWED_HOSTS` failed silently: it now logs a WARNING.
  - Forged-Host refusals were unlogged.
  - Smoke read the commit from `/health`, which is rightly 503 during a Protect outage: it now reads `/health/live`.
  - `refuse_released` failed open on "404 page not found" / "repository not found".
  - The release tag check read local tags only: it is now `git ls-remote` against origin, fail closed.
  - IPv6-literal hosts are documented as unsupported.
  - The `color_message` leak was escalated (LUXUPT-87), now fixed.
  - The dead `_create_timelapse_record` is awaiting an owner ruling.
- **`make dev-deploy` failed its own smoke** by probing before the app had started. `dev-pin` now runs `compose up --wait`.

## Refactors

- **Crud owns session writes** (`fw.no_session_mutation_outside_crud`). The settings singletons are seeded via each settings crud's `seed_default`. The timelapse record goes through `timelapse_crud.create(TimelapseCreate)`; `TimelapseCreate` gained `thumbnail_path` and `completed_at`. Durability locks: `test_seed_and_create_durable`.
- **Card view-models** (`fw.no_template_logic`): views hand templates `{job|timelapse|capture, urls}` cards instead of URL maps keyed by id.
- **Fleet logging module** (`repo.logging_canonical`, `repo.log_fields_explicit`): `app/core/logging_config.py` is luxarch's emitted logging v6, and `configure_logging` runs in both entrypoints and alembic's `env.py` (no more `fileConfig`). python-json-logger is gone; modules use `logging.getLogger`. **JSON line shape:** caller fields now sit under `attributes.<key>`.
- The shared Jinja instance → `app/web/templates.py`. Error pages → `pages/errors/`. `is_https_request` is public. Activity `offset` → `skip`.
- `/health*` declare Pydantic response models; `HealthStatus` is a StrEnum in `enum_model`. `/health` and `/health/live` report `commit`.
- Re-emitted assets: gitleaks v11, buildx-setup v2, route-smoke v20, exception-handler v2, naming-convention v3, changelog-guide v2, htmx-error-swap v2, migration-chain v2, logging v6, hooks, and seven fleet skills (fleet-start, luxpm-audit and adversarial are new).

## Schema / Migrations

No new revisions. `app/db/migrations/env.py` calls `configure_logging` instead of `fileConfig`, so the post-migration logging re-init in `database.py` is gone.

## Infra / Ops

- **Dockerfile stages:** `builder`, `builder-dev`, `css` (node), `app`, `test`, `production`. `production` is last, so a bare `docker build` ships no test tooling; deploy builds pass `--target production`. `app/static/css/app.css` is compiled from `input.css` in the css stage and gitignored (was `compiled.css`, committed). `make css-watch` replaces the host-npm targets.
- **`make test` is luxarch's emitted test block:** the `test` image, source mounted read-only, branch coverage under sysmon, ratchet floor 54%. `pytest-cov` → `coverage`. SQLite needs no backing service.
- **`make smoke SITE=<site>`** runs at the end of `make dev-deploy`. `SMOKE_URL_<site>` lives in the gitignored `Makefile.local`.
- **Release:** `release` refuses a VERSION already in the registry (fail closed) or tagged on origin at another commit; `release-public` refuses an existing GHCR tag. `docker-build-local` loads the bare `luxupt:local`.
- **Ports:** nginx publishes 11000/11001 (the fleet per-app block), on the dev node and the prod node (`prod/`, gitignored).
- **BB:** `UNIFI_PROTECT_BASE_URL` now names the NVR (gitignored env), with a key issued by the NVR.
