## Fixes

- **LUXUPT-6** — a stale `override_deletion` NOT NULL column in `jobs` caused an IntegrityError on every job INSERT (migration 001 added `keep_images` as its replacement but never dropped the old column). Migration 002 drops it.
- **LUXUPT-3** — scheduler cleanup passed `camera_safe_name` (e.g. `Garage_Cam`) to CRUD methods that filter on `camera_id` (UUID) → 0 rows matched, so nothing was ever cleaned. Resolve safe_name → UUID before cleanup.
- **LUXUPT-5** — Alembic's `fileConfig()` defaults `disable_existing_loggers=True`, silently killing app loggers after migrations run. Set it False + call `setup_logging()` in the migration finally block.
- **LUXUPT-2** — the capture toggle had no effect on the fetch scheduler.
- **LUXUPT-7** — detect H.265/HEVC codec errors and log an actionable "switch to Standard encoding"; full FFmpeg stderr at DEBUG; truncation 100→500 chars; getting-started + troubleshooting docs updated.
- **LUXUPT-8** — FFmpeg killed with no output (common with OOM in LXC) now logs likely-OOM instead of a generic failure; stderr at DEBUG; truncation 200→500; troubleshooting docs updated.

## Schema / Migrations

- **Migration 002** — drops the stale, unused `override_deletion` column from `jobs`.
