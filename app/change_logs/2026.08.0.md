## Fixes

- **Timelapse jobs could vanish mid-flight.** `JobProcessor.start_job` discarded its `asyncio.create_task` result, so the event loop held only a weak reference and an in-flight job could be garbage-collected with no error and no log (ruff RUF006).
- **Two camera links returned nothing.** The camera panel's "View Images" and "Timelapses" sent `safe_name` into a `camera_id` (UUID) column — zero rows every time, while the filter dropdowns on the same pages already sent the UUID.
- **The "timelapse already exists" check never fired** — it compared a safe name against the UUID column, so it could re-encode work that already existed.
- **13 timelapse rows were invisible to the UI** — a retired code path wrote `camera_id=""`. Repaired by migration `9f3d0d41053d`.
- **GET page renders wrote to the database.** The settings CRUDs were lazy get-or-create and the users page synced the env user on every render, so 13 GET routes reached a write — CSRF-reachable under `SameSite=Lax` (`fw.state_changing_get`, now 0).
- **The About page rendered blank values** — it read three `config` keys the view never provided; exposed by turning on `StrictUndefined`.
- **A flaky test was a real test bug.** `test_tampered_token_rejected` rewrote the LAST base64 character of a JWT signature; that character carries only 4 significant bits, so for 3 of 64 values the tamper decoded to the same bytes and the token stayed valid (~4.7% of runs).
- Blocking `pathlib`/`os.path` calls moved off the event loop (ruff ASYNC240).

## Refactors

- **Two session owners.** Added `get_db_context` (the non-request owner) and routed all 46 raw `async_session()` mints through `get_db` / `get_db_context`. A raw factory session in a background path never commits and takes a second pooled connection.
- **The view seam owns its web outcome** — `fw.no_passthrough_view_service` to 0; routers thinned to "receive request → call one service method → return the response".
- **Templates render, they do not compute** — `fw.no_template_logic` to 0. Duplicated camera/date option shaping moved into the view layer; URL assembly moved out of templates (and now escapes via `urlencode`).
- **UI composes macros** — `fw.no_hand_rolled_components_in_pages` 75 → 15; library gained `toggle_row`, `radio_card` (card/list/tile), and `text_input(suffix=, align=)`.
- **One name per threaded value** — `fw.no_threaded_aliasing` to 0; CRUD parameters renamed to the columns they filter.
- Display formatting moved to the edge (`fw.strftime_is_display_only` to 0); recording-range bounds now render in the viewer's timezone rather than the server's.

## Schema / Migrations

- `a2d380f58938` — **baseline schema (additive, structural).** The chain had six revisions and zero `create_table`: `alembic upgrade head` on an empty database died on revision 001. The schema was only ever built by `create_all`, so migrations had never been exercised from empty and no fresh provisioning path worked. Baseline added and the chain re-rooted. `alembic heads` is still `006`, so existing deployments are already at head and unaffected.
- `9f3d0d41053d` — **data backfill (non-destructive).** Fills `camera_id` on timelapse rows written with `""`, only where the safe name resolves to exactly one camera. Downgrade is a no-op.
- `MetaData` now carries the canonical fleet `naming_convention`.

## Infra / Ops

- **Python 3.13 → 3.14** across pyproject, both Dockerfile stages, the poetry-in-docker image and `[python].target`; lock regenerated cleanly.
- **`make check` is the canonical gate**: `guard-version-check honest lint mypy test db-verify arch audit gitleaks`. The previous gate silently omitted mypy and gitleaks.
- **`guard-version-check` is now FATAL** — a stale guard pin fails the gate instead of printing a warning nobody acts on.
- **`make db-verify`** — fresh empty DB → `alembic upgrade head` → diff vs models, failing on ANY structural diff. This is what caught the missing baseline.
- **Test isolation** — the suite sources a dedicated `TEST_DATABASE_URL` with a dev-DB guard, and `make test` creates and wipes the throwaway database.
- **`make status`** publishes `.lux*-status.json` for the fleet reader.
- Guards repinned: luxarch 0.153.0, luxlint 0.45.1, luxaudit 0.4.0.
- **Internal topology removed from the committed tree** — the Makefile prod block was parameterised, with real values moved to the gitignored `Makefile.local`; a personal name was removed from the startup banner. Repository history was scrubbed on `dev`.
