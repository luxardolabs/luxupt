## Fixes

- **GET /setup 500'd on a fresh install** (no env auth, no users), with `'errors' is undefined` under StrictUndefined. This is the first page a new user sees. The GET passed `{}`, and the template reads `errors` unguarded. Found by route-smoke asserter v19, which no longer counts a GET that only ever 3xx's as covered: the suite had only ever seen `/setup` redirect.
- **A wrong-password login 500'd** (`'success' is undefined`) instead of rendering "Invalid username or password". The same class of bug, found by the new rate-limit test.
- **Two latent circular imports**, each only working because of import order: `config` ↔ `logging_config` (an unused logger in config), and `app.services` re-exporting every core service, which pulled `job_core_service` → `timelapse_service` into a cycle. Every worker, client, CLI and web module now imports cleanly on its own.
- **A failed migration no longer boots the app.** `init_db` used to run `create_all` and then log any migration failure as a warning. Startup now migrates only, and raises on failure.

## Refactors

- **Module homes (FLEET-LAYOUT-STANDARD §2):**
  - `app/core/`: config, logging_config, startup
  - `app/clients/`: protect_client, camera_manager
  - `app/workers/`: fetch_service, timelapse_service
  - `app/cli/commands.py` (was `app/cli.py`)
  - `app/db/connection.py` → `app/db/database.py`; the `DbSession` alias → `app/web/deps.py`
  - Imports changed at source. The `app.db`, `app.services` and `app.services.views` re-export shims are gone.
- **`fw.file_size`:** `timelapse_service.py` 1621 → 1392 LOC. The split-plan sweep found no domain seam, so the size was decomposed inside `_create_video`. The ffmpeg/ffprobe plumbing moved to `app/utils/ffmpeg.py`, which also replaces byte-identical private copies of the probe and thumbnail code in `job_core_service`. The four duplicated failure-cleanup blocks are one `_fail_video()`.
- **Login rate limiting is slowapi** (FLEET-RATE-LIMIT-STANDARD), replacing the hand-rolled per-IP dict in `auth.py`. It is keyed on nginx's `X-Real-IP`, not the client-controllable first `X-Forwarded-For` entry.
- **Test harness** on luxlint's canonical conftest, adapted for SQLite. The schema is built once from `alembic upgrade head` into a template file (never `create_all`), each test runs on its own copy, the app's session maker is swapped per test, and `db` is a savepoint session. Route-smoke asserter v12 → v19.
- **Re-emitted fleet assets** with version markers: gitleaks v9 (digest-pinned scanner and a commit-identity pass), migration-chain v3, exception-handler, htmx-error-swap, naming-convention (now `app/db/naming_convention.py`), buildx-setup, guard-upgrade, both writing guides, the `.claude` hooks and the four fleet skills, and the git hooks.

## Infra / Ops

- **Dependencies at the fleet floors:** SQLAlchemy 2.0.51 → 2.1.3, FastAPI 0.140.0 → 0.141.1, uvicorn 0.40.0 → 0.52.4, alembic 1.18.5 → 1.20.0. No 2.1 breakers in the code; the suite is green under `filterwarnings = error`.
- **CVE fixes:** pyjwt 2.13.0 → 2.15.1 (13 advisories), urllib3 2.7.0 → 2.8.0. Added slowapi 0.1.10 / limits 5.8.0. Dropped the guard-owned tools (black, isort, flake8, mypy, pre-commit, ruff) from the dev group.
- **Image:** the runtime stage runs `apt-get upgrade` and uninstalls pip from both the venv and the system interpreter. The released 2026.09.0 image carried 17 fixable HIGH/CRITICAL findings; this build scans 0.
- **Release pipeline (image-block v5):** `make release` builds a `candidate-<commit>` image, scans every platform with `luxaudit --image-archive`, and only then tags `sha-<commit>`, `:VERSION` and `:latest` from it. `release-public` promotes the same digest to GHCR.
- **Dev stacks pin an immutable tag:** `make dev-deploy SITE=<site>` / `make dev-pin`. `build-dev` and the moving `:dev` tag are retired.
- **Rate limit store is per-process memory.** luxupt runs one uvicorn worker and has no Redis. Raising `UVICORN_WORKERS` multiplies the login limit by the worker count. `WEB_LOGIN_RATE_LIMIT` / `WEB_LOGIN_RATE_WINDOW_SECONDS` still set it; every attempt now counts, not just failures.
- **No fixed `/tmp` paths in the Makefile:** per-run `mktemp` files, and the test/verify databases go under the gitignored `.cache/`.

## Known reds

- luxaudit's image leg on the published `2026.09.0` image (17 fixable). By design, it is cleared by releasing this version.
