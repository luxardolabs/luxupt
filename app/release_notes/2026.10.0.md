# 2026.10.0 — 2026-10-03

Two pages that could fail on a brand-new install now work, sign-in is protected against password guessing, and the app ships on an updated, security-patched image.

## FIXED

- **The first-run setup page could fail to load** `Setup` — On a fresh install with no accounts yet, opening the setup page showed an error instead of the "create your account" form.
- **A wrong password showed an error page** `Sign in` — Mistyping your password now shows "Invalid username or password" instead of an error page.
- **The app no longer starts on a half-upgraded database** `System` — If a database upgrade fails during startup, the app now stops and says so, instead of starting anyway and failing later in confusing ways.

## IMPROVED

- **Sign-in is protected against password guessing** `Sign in` — Repeated attempts from the same address are paused for a short while, with a message saying how long to wait. The limit is still set by `WEB_LOGIN_RATE_LIMIT` and `WEB_LOGIN_RATE_WINDOW_SECONDS`.
- **A more secure container image** `Everywhere` — The image ships with current security fixes for its operating system and libraries, including several for the sign-in token library. Every release is now scanned before it is published.

## Upgrading

Nothing to do first. The database migrates on start, and there are no schema changes this release.

If you run more than one web worker (`UVICORN_WORKERS` above 1), the sign-in limit applies per worker. The default of one worker is what it is designed for.
