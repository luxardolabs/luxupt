# 2026.10.2 — 2026-10-31

Accounts now live in the app itself, settings forms check what you enter, and pages stay responsive while the app talks to your cameras.

These notes use the app's surfaces as labels: Sign-in, Cameras, Timelapses, Images, System and Everywhere.

## Upgrading

Do these before or right after restarting on this version:

- **List your site's hostnames:** set ALLOWED_HOSTS in each environment file to every name the site is reached by, without ports. The app will not start without it.
- **Reset the old login once:** signing in with the username and password from the environment file no longer works. After the upgrade, run docker exec <stack> python -m app.cli reset-password <username> and sign in with the one-time password it prints; you'll be asked to choose a new one.

## NEW

- **Accounts are managed in the app** `Sign-in` — The first admin is created on a setup page (or from settings you provide once), a forgotten password is reset with one command, and a new or reset password must be changed on first sign-in.
- **Changing your password signs out your other sessions** `Sign-in` — Any browser still signed in with the old password has to sign in again.

## IMPROVED

- **Pages stay quick while the app talks to your cameras** `Everywhere` — Testing the Protect connection, detecting a camera's capabilities, opening the historical panel or loading a video no longer freezes every other page until the camera or console answers.
- **Settings forms tell you what's wrong** `System` — Every settings form checks each value against its allowed range and names the field it refuses, instead of saving a value that breaks things later.
- **Backups stay inside your data folder** `System` — The backup folder must be a folder inside the output directory, so a typo can't write your database copy somewhere else.
- **Reliability** `Everywhere` — Lots of behind-the-scenes stability, security and build work, including updated image libraries.

## FIXED

- **Edit and Delete did nothing on the users list** `System` — Each user's Edit and Delete buttons now open and delete that user.
- **The camera Detect button did nothing** `Cameras` — Detecting a camera's capabilities from its settings panel works again.
- **Saving Protect settings could hang and report a failed connection** `Cameras` — Saving now connects and reports the cameras it found.
- **Sign-in sometimes failed with an error while cameras were capturing** `Sign-in` — Logins succeed even when the app is recording captures at the same moment.
- **Cancelling a job could undo a finished timelapse** `Timelapses` — A cancel that arrives after the job has completed no longer marks it cancelled.
