# 2026.11.0 — 2026-11-19

Safer accounts, deletes that remove only what you asked for, and fewer error pages.

These notes use the app's surfaces as labels: Sign-in, Cameras, Timelapses, Images, System and Everywhere.

## Upgrading

- **Everyone signs in again:** existing sessions end when you upgrade.
- **Coming from 2026.10.1:** follow the 2026.10.2 upgrade steps too: list your site's hostnames in ALLOWED_HOSTS, and reset the old login once with docker exec <stack> python -m app.cli reset-password <username>.

## NEW

- **Read-only accounts** `Everywhere` — Users who aren't admins can browse, download and change their own password, but can no longer delete, stop capture or change settings.
- **Error pages show a reference** `Everywhere` — If something goes wrong, the error page shows a reference you can quote when reporting it.

## IMPROVED

- **Your camera credentials stay hidden** `Cameras` `System` — Only admins see the Protect and backup settings, and saved keys and passwords are never shown on the page; leave a field blank to keep what's saved.
- **Forms tell you which field is wrong** `Everywhere` — A form you submit with a bad value names the field instead of failing.
- **New usernames follow one rule** `System` — Usernames you create or rename use letters, digits, dots, underscores and dashes, the same as on the setup page.
- **Reliability** `Everywhere` — Lots of behind-the-scenes security and stability work.

## FIXED

- **The image delete panel showed an error** `Images` — It works again, and deletes only the images its preview showed you.
- **Making a timelapse could delete other cameras' images** `Timelapses` — Only the frames that went into the video are removed.
- **A job's "keep images" choice was ignored** `Timelapses` — Each job now keeps or removes its images as you chose.
- **Deleting one camera's images could remove another's thumbnails** `Images` — Only that camera's thumbnails are removed.
- **Odd dates or intervals in a link showed an error page** `Images` `Timelapses` — They're now ignored or refused cleanly.
- **An admin could change their own password without the current one** `System` — Your own password is changed only from your account page.
- **Capture errors showed the camera's stream address** `Cameras` — Error messages now explain what failed without revealing it.
