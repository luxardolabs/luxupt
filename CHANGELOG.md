# Change Log

Per-version technical change logs live in [`app/change_logs/`](app/change_logs/) — one file per released VERSION, written for whoever is debugging "what changed in this version".

- Current: [`app/change_logs/2026.10.2.md`](app/change_logs/2026.10.2.md)
- Format: [`app/change_logs/writing-guide.md`](app/change_logs/writing-guide.md)

The user-facing half is [`RELEASE_NOTES.md`](RELEASE_NOTES.md). The process that produces both is `luxarch --doc FLEET-RELEASE-PROCESS`.

Versions are CalVer `YYYY.0M.MICRO`; the `1.1.x` line is legacy.
